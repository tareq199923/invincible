Connecting a client

  • Register it: POST /oauth/register (dynamic client registration; send redirect_uris and a client_name).
  • Send the user to GET /oauth/authorize with PKCE (S256); consent is granted in the browser.
  • Exchange the code at POST /oauth/token; call POST /mcp with Authorization: Bearer <access_token>.
  • Revoking a client's tokens below cuts off its live access immediately.

API keys (inv_...) are not accepted on /mcp — OAuth bearer tokens only (owner decision, Q1).
